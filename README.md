# Promptopia

Promptopia is an open-source AI prompting tool to discover, create, and share creative prompts. It provides a simple and intuitive platform for users to explore prompts, contribute their own, and manage content efficiently.

## 🚀 Tech Stack

- Next.js 13
- TypeScript
- Tailwind CSS
- MongoDB

## ✨ Features

- 🔍 Discover creative AI prompts from the community  
- ✍️ Create and share your own prompts  
- 🗂️ Manage prompts with full CRUD functionality  
- 🔐 User authentication and personalized experience  
- ⚡ Fast and responsive UI with modern design
